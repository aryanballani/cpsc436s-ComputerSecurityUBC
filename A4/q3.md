If two messages are signed with the same nonce: \\

- r = r1 = r2 = ($g^k$ mod p) mod q
- $s_1$ = $k^{-1}$($m_1$ + xr) mod q
- $s_2$ = $k^{-1}$($m_2$ + xr) mod q
- $s_2$ = $s_1$ = $k^{-1}$($m_1− m_2$) mod q
